# Leakage-free chatter-detection benchmark: thin-wall milling of WAAM ER5356 and wrought AA 5052

This is the second paper extending our *Materials* study (Sundaram et al., *Materials* 2026, 19, 2653,
doi:10.3390/ma19122653). It uses cutting force (Kistler 9257B, 25 kHz) and triaxial vibration (25 kHz)
from face-milling of thin walls to benchmark zone-level chatter detection.

Framing C applies (`DECISION.md`): a small-data, leakage-free benchmark. Thermal data, roughness
prediction and material-specific claims are out of scope. The target journal is MDPI *JMMP*.

## Key findings in plain language

1. **The archive's trial mapping was partly wrong.** The spindle speed measured from each force
   spectrum disagrees with the recorded speed for trials 06, 11 and 16. The speed blocks and the rising
   force within each block point to a specimen change between trials 11 and 12, one trial later than
   assumed. No trial with a force record has a confirmed material (`audit/trial_mapping_evidence.md`).
2. **The old labels used nominal spindle speeds.** These are too inaccurate for a ±2 Hz harmonic test
   near 3.5 kHz; labels now use the measured speed.
3. **Labels hinge on the dB threshold.** With 3 zones per wall, 15 / 20 / 25 dB give 25 / 1 / 0
   unstable zones out of 48, so only 15 dB can be evaluated.
4. **The benchmark results** (pooled AUC, CIs, permutation nulls, paired tests) are in
   `results/metrics.csv` and `results/paired_tests.csv`, and summarised in `DECISION.md`.

## How to reproduce

```
python -m pip install -r requirements.txt
python run_pipeline.py test        # 23 unit tests
python run_pipeline.py prepare     # raw CSVs -> zone features and labels (~1 min)
python run_pipeline.py mapping     # trial-mapping evidence
python run_pipeline.py train       # LOTO benchmark, 9 models x 5 seeds (~2.5 h on 6 cores)
python run_pipeline.py evaluate    # metrics, CIs, nulls, paired tests -> results/
python run_pipeline.py figures     # paper/figures/
python run_pipeline.py paper       # paper/manuscript.docx + check_numbers.py
python run_pipeline.py pdf         # LibreOffice PDF, page PNGs, blank-equation/glyph check
```

`paper/omml.py` converts LaTeX to native Word equations using Office's `MML2OMML.XSL` (Microsoft
Office must be installed). `check_pdf.py` looks for LibreOffice in the default install folder or in
the `SOFFICE_PATH` environment variable.
